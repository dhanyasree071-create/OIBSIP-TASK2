# Unemployment Analysis with Python 📊

## 📌 Description
This Data Science project focuses on analyzing unemployment trends in India using Python and data visualization techniques. The analysis helps understand unemployment patterns across different regions and highlights the impact of unemployment during the Covid-19 period.

## 🎯 Objective
The objective of this project is to analyze unemployment data and visualize unemployment trends across India using various data science techniques.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 📂 Dataset
The dataset contains:
- Estimated Unemployment Rate (%)
- Estimated Employed Population
- Labour Participation Rate (%)
- Region-wise unemployment statistics

## 📊 Data Science Workflow
- Data Collection
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Correlation Analysis
- Data Visualization
- Region-wise Unemployment Analysis
- Trend Analysis

## 📈 Visualizations
The project includes:
- Heatmaps
- Bar Charts
- Histogram Plots
- Distribution Graphs

## 🚀 How to Run
1. Install required libraries:
```bash
pip install -r requirements.txt
```

2. Run the notebook:
```bash
unemployment_analysis.ipynb
```
